# Stop This Planet — public website

Official manifesto and project information for Stop This Planet by ELSEVANE.
Canonical address: https://stopthisplanet.com/.

Buildless HTML, CSS and JavaScript. No package installation is needed. Serve this
directory with a static HTTP server to preview it. GitHub Pages publishes `main`
from the repository root. `CNAME` preserves the custom domain on later updates.

The website presents the manifesto and information. It has no checkout, account
login, customer records, analytics or advertising. The application remains in
internal testing. Existing privacy and deletion services remain at their current
canonical locations and are linked from the website.

Manifesto text and translations come from the application canon. Source artwork,
CSS, icon and layout are original project material. System fonts are used; no
third-party images or font services are loaded. All rights reserved, ELSEVANE.
